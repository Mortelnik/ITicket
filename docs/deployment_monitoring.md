# Деплой и мониторинг

## Маршрут запуска (учебный, проверен)

Локальный маршрут полностью проверен командой:

```bash
uv sync --locked          # воспроизводимые зависимости из uv.lock
bash scripts/download_data.sh
uv run ticket-router-train # эксперименты + артефакт artifacts/model.joblib
uv run pytest -q           # 14 тестов
uv run uvicorn ticket_router.api:app --port 8000
curl -X POST localhost:8000/predict -H 'Content-Type: application/json' \
  -d '{"subject":"Login failed","body":"Cannot log into my account, error 500"}'
```

## Контейнеризация

`Dockerfile` собирает образ: python:3.12-slim, зависимости через `uv sync --locked`,
артефакт модели копируется в образ, healthcheck на `/health`.

Честное примечание: в среде разработки Docker-демон был недоступен, сборка
контейнера не выполнялась. Маршрут внутри контейнера (uvicorn на порту 8000)
идентичен проверенному локальному запуску; первый шаг следующей итерации —
`docker build . && docker run -p 8000:8000` и повторный smoke-тест.

В реальном проекте артефакт модели не запекался бы в образ, а подтягивался из
model registry (MLflow/S3) при деплое — образ остаётся универсальным, версия
модели управляется отдельно.

## Мониторинг

### Технические метрики (реализованы в `/metrics`, счётчики в памяти)

| Метрика | Где | Действие |
|---|---|---|
| predictions_total / errors_total / error_rate | `/metrics` | рост — investigate логов |
| latency p95 (план) | middleware → Prometheus | см. алерт 1 |
| uptime / model_loaded | `/health` | model_loaded=false → откат |

### Метрики данных/модели (план)

| Метрика | Что ловит |
|---|---|
| доля предсказанных классов (реализована в `/metrics`) | дрейф распределения предсказаний |
| доля пустых subject+body на входе | поломку интеграций апстрима |
| macro-F1 на отложенной разметке | деградацию качества |

### Алерты

1. **Технический (главный):** доля HTTP 5xx > 5% за 5 минут при ≥ 100 запросах →
   проверить подложен ли артефакт (`/health.model_loaded`) и ресурсы пода;
   при повторении — откат на предыдущую версию Deployment.
   Порог начальный, взят из здравого смысла, не из SLA.
2. **Модельный:** доля предсказаний самого частого класса выросла с ~29% до
   > 40% за сутки → вероятен дрейф данных или поломка векторизации →
   сравнить распределение длины текста на входе, отправить сэмпл на разметку,
   пересчитать macro-F1 на свежих метках.

### Важно

- Полнные тексты обращений не логируются (PII): только хэш, длина и предсказание.
- Сдвиг распределения предсказанных классов сам по себе не доказывает падение
  качества — подтверждать только метриками на отложенной разметке.
- Метрики качества считаются только когда появляется размеченный поток
  (текущие тестовые данные — статичные).
